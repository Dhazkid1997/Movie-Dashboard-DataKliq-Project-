## 📌 Project Overview

This project focuses on developing an interactive **Movie Analytics Dashboard** using Microsoft Power BI to explore and visualize movie-related data.

Developed as part of the **Data Kliq – Cohort 2** learning experience, the project demonstrates the application of data analytics and business intelligence techniques to transform raw movie data into meaningful visual insights.

The dashboard provides an interactive platform for exploring movie-related information, identifying patterns, and understanding trends through data visualization and analytical reporting.

## 🎯 Project Objectives

- Explore and analyze movie-related datasets.
- Identify patterns and trends within the movie industry.
- Transform raw data into meaningful visual insights.
- Develop an interactive dashboard for effective data exploration.
- Apply DAX calculations and measures to support analytical reporting.
- Enhance data storytelling through effective visualization techniques.
